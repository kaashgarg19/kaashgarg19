# Dataset

## Overview

The project uses environmental sensor data collected from IoT devices.

The working dataset contains:

- 405,184 rows
- 9 columns
- 3 IoT devices
- 6 main environmental sensor measurements
- A `motion` field used as the prediction target

## Sensor information

The main environmental measurements include:

- Carbon monoxide (`co`)
- Humidity (`humidity`)
- Light (`light`)
- LPG (`lpg`)
- Smoke (`smoke`)
- Temperature (`temp`)

## Target

The `motion` field indicates whether movement was recorded.

The raw dataset is not stored in this repository. The dataset source and licence information will be documented once verified.
