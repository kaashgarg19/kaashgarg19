# Basic Methodology

The project follows a simple machine-learning workflow.

## 1. Data preparation

The IoT sensor data is loaded and checked for its structure and quality.

## 2. Data exploration

The sensor measurements are explored using basic statistics and visualisations.

## 3. Data preparation for modelling

The relevant features are prepared for machine-learning models and the movement field is used as the target.

## 4. Model training

Machine-learning classification models are trained using the prepared data.

## 5. Evaluation

The models are compared using appropriate classification measures and their results are documented.

This is the basic methodology for the project. More detailed experimental work will be documented separately later.
