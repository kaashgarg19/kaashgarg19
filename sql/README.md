# SQL & Analytics Projects

This section contains small SQL analysis projects and practice work.

## Bike Sales SQL Analysis

A SQL analysis exercise using bike sales data.

The work covers:

- Linking customers with the products they purchased
- Finding the top 5 products by revenue
- Finding the top 5 customers by number of orders

The queries are available in [bike_sales_analysis.sql](bike_sales_analysis.sql).

This is practice/project work focused on SQL querying, joins, aggregation, grouping and ordering.
